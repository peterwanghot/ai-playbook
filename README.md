# AI Playbook

这里记录并分享工作中的实践经验：从问题分析、工具使用到流程沉淀。

内容会随着实际项目持续更新，侧重可复用的方法、清晰的操作步骤和复盘结论。

## 资料目录

### [Notion Local Ops MCP 完整部署 SOP](https://github.com/peterwanghot/ai-playbook/blob/main/Notion-Local-Ops-MCP-SOP.pdf)

将 Notion Agent 接入本地代码仓库的部署手册。内容包括 macOS 和 Windows 的环境准备、`notion-local-ops-mcp` 安装与 `.env` 配置，以及通过 Cloudflare Quick Tunnel 快速试用或 Named Tunnel 长期运行的两种接入方案；同时说明 Notion MCP 配置、后台常驻、常见使用指令与安全注意事项。
